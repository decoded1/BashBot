# Marketplace CLI Tools Reference

## Craigslist Tools

- **clscrape** - https://github.com/jseconners/clscrape
  Command line Craigslist scraper outputs JSON with structured listing data

- **CraigslistScraper** - https://github.com/ryanirl/CraigslistScraper
  Lightweight Python library for scraping Craigslist from terminal sessions

- **SearchExpander** - https://github.com/Same-Writer/SearchExpander
  Scrapes Craigslist across multiple cities with email notifications support

- **craigslist_scraper** - https://github.com/ebtrader/craigslist_scraper
  Scrapes Craigslist pages and ranks most common listings found

- **craigslist-scraper** - https://github.com/tylernnguyen5/craigslist-scraper
  Extracts job listings from Craigslist using Puppeteer and Cheerio

- **cl_gig** - https://github.com/michaelrinderle/cl_gig
  Scrapes Craigslist computer gigs and outputs to HTML file

## OfferUp Tools

- **Apify OfferUp Scraper** - https://apify.com/igolaizola/offerup-scraper
  Extract OfferUp listings by keyword and ZIP code via CLI

- **offerup** - https://github.com/planetzero/offerup
  Unofficial OfferUp API client for programmatic marketplace access

- **OfferupUnofficalAPI** - https://github.com/everettperiman/OfferupUnofficalAPI
  Unofficial API for OfferUp ecommerce site marketplace operations

## Facebook Marketplace Tools

- **Apify FB Marketplace Scraper** - https://apify.com/apify/facebook-marketplace-scraper
  Extract Facebook Marketplace products with prices and seller details

- **facebook-marketplace-scraper** - https://github.com/passivebot/facebook-marketplace-scraper
  Scrapes Facebook Marketplace using Playwright BeautifulSoup and Streamlit

- **Apify FB Marketplace Cheerio** - https://apify.com/memo23/facebook-marketplace-cheerio
  Fast Facebook Marketplace scraper using Cheerio for data extraction

## eBay Tools

- **Apify eBay Listings Scraper** - https://apify.com/piotrv1001/ebay-listings-scraper
  eBay listings scraper installable via npm apify-cli command line

- **Apify eBay Scraper (Rental)** - https://apify.com/3x1t/ebay-scraper
  Scrapes eBay product listings with rental options via CLI

- **Apify eBay Search Scraper** - https://apify.com/jwlben11/my-ebay-scraper
  Scrapes eBay search results pages through Apify CLI interface

- **Apify eBay Products Scraper** - https://apify.com/xmiso_scrapers/ebay-products-easy-scraper
  Fast lightweight eBay scraper processing two thousand products per minute

- **Apify eBay Seller Scraper** - https://apify.com/lucascode/ebay-seller-scraper
  Extracts eBay seller information and listings through API calls

## Etsy Tools

- **Getsy (WWW::Getsy)** - https://github.com/jgoulah/WWW-Getsy
  Perl command line interface to Etsy V2 OAuth API

## Multi-Platform Tools

- **Deals-Scraper** - https://github.com/JustSxm/Deals-Scraper
  Scrapes Facebook Marketplace Kijiji eBay Amazon and Lespacs deals

- **marketplace-scraper** - https://github.com/johudsonRx/marketplace-scraper
  Scrapes Craigslist and other marketplaces for targeted buying opportunities

## API Services (CLI Compatible)

- **ZenRows** - https://www.zenrows.com/blog/ebay-web-scraping
  Python terminal based API for eBay scraping with rotation

- **Crawlbase Crawling API** - https://crawlbase.com/blog/how-to-scrape-ebay-using-javascript/
  Crawling API with built-in eBay scraper for search results

- **ScraperAPI** - https://www.scraperapi.com/web-scraping/ebay/
  Supports Python and JavaScript implementations for eBay marketplace scraping

- **ScrapingAnt** - https://scrapingant.com/blog/scrape-ebay-python
  Python API for eBay scraping accessible through terminal

- **Bright Data FB Scraper** - https://brightdata.com/products/web-scraper/facebook/marketplace
  Facebook Marketplace scraper API for automated data extraction
